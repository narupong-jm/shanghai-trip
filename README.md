# Shanghai Autumn Trip · 2–8 Dec 2026

Mobile-first travel guide for a 7D6N Shanghai trip (Mm & Pajaryy).
Static site — no build step. `index.html` + `images/`.

Contents: Overview, Member, Flight, Hotel (photo popup), day-by-day itinerary
(Day 1–7, Disneyland Tier 1–4 with ride photos), 36 restaurants with day filter,
6 spare locations. Every place card has 3–4 swipeable photos.

Deploy: static, output directory = repository root.
